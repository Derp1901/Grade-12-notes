Adjust based on your strengths, school workload and official syllabus. Daily session targets are suggested practice counts, **not exam question distribution**.

### If Dataview still shows errors
- Check Settings → Community plugins → Dataview is installed and enabled; open the dashboard in Reading view (or Live Preview).
- If only the `INPUT[...]` dropdown text is visible, enable **Meta Bind**. It is separate from Dataview.
- If only the `tasks` code block is visible, enable the **Tasks** plugin.
- Dataview grouped subject counts now use `key` as the group name. No JavaScript queries are needed.
- If the issue persists, copy the **exact error text** from Obsidian or take a screenshot; packaging cannot prove plugin rendering.

**Already started studying?** Apply the appearance-only patch ZIP instead of replacing chapter and daily notes. That patch only contains the dashboard/checklist hub, subject checklists, original styling, and this README.
